# PsychologyAtlas в Obsidian

Готовая база поставляется переносимым ZIP в закрытой папке Google Drive с результатами проверки, вне учебных источников. В Git остаются средства подготовки; скачивание GitHub ZIP само по себе не даёт готовый Vault. Точная ссылка и проверенный digest передаются владельцу приватно.

Скачайте проверенный архив, распакуйте в отдельную папку и в Obsidian выберите **Открыть папку как хранилище**. Укажите распакованную папку и начните со страницы `generated/База знаний.md`. Обычные Markdown, поиск, wikilinks, обратные ссылки и граф доступны без дополнительных плагинов и подписки для чтения офлайн. Другому устройству нужен собственный перенос архива.

Каждая заметка раскрывает понятие, механизм или различение; связи объясняют отношения между знаниями. Тематические обзоры дают точки входа. Дата, фактическое покрытие и исключения указаны внутри пакета. Наличие заметки не подтверждает весь исходный материал; вопросы теста и книжный каталог не заменяют базу знаний.

Личные заметки храните вне `generated/`, настройки — в `.obsidian/`. Приложение не читает их и не связывает с учебным прогрессом. Готовый пакет не содержит личных файлов, исходных учебных текстов или точных приватных координат проверок.

Перед обновлением сохраните свою папку. Не распаковывайте новый `generated/` поверх старого: [проверяемое обновление](../docs/obsidian-vault.md#обновление-существующего-хранилища) сначала проверяет управляемые файлы и личные ссылки. Личная правка, неизвестный файл, повреждённый state или исчезающий заголовок/блок останавливают замену до записи. Остальные файлы и настройки остаются без изменений.

Vault не является разделом Telegram, Mini App или PWA и не включается в assets или контейнеры. История прежних решений сохранена в [spec](../docs/project-spec.md); действующий способ поставки задаёт D-71.
