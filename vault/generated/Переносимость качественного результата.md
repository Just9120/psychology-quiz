# Переносимость качественного результата

Переносимость предполагает осмысленное сопоставление подробно описанного опыта и условий с другим контекстом. Контекст позволяет читателю оценить применимость вывода. Это не статистическое обобщение на всех людей и не синоним количественной репрезентативности.
