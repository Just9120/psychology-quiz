# В исторической типологии человек сравнительно легко меняет одну задачу на другую. С каким свойством нервных процессов соотносится такое описание в модели?

[[topic-1bbf039f694a506dc75b|Лекция 1. Основные понятия физиологии ВНД]]


## Вопрос

В исторической типологии человек сравнительно легко меняет одну задачу на другую. С каким свойством нервных процессов соотносится такое описание в модели?

## Варианты

1. С силой, то есть длительной работоспособностью при нагрузке
2. С уравновешенностью, то есть соотношением возбуждения и торможения
3. С подвижностью, то есть переключением видов деятельности
4. С сенсорным порогом, то есть обнаружением слабого сигнала

## Ответ и пояснение

С подвижностью, то есть переключением видов деятельности

Переключение видов деятельности в этой схеме связано с подвижностью нервных процессов. Сила и уравновешенность описывают другие свойства, а сенсорный порог — другое основание оценки. Это иллюстрация значения термина, не способ надёжно измерить свойство человека по одному эпизоду.
