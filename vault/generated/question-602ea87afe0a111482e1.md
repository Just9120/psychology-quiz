# Результат теста сравнивают с данными группы, на которой получены нормы. Что прежде всего нужно проверить для такого сравнения?

[[topic-231adfac937b8dac7fcc|Практика №22]]


## Вопрос

Результат теста сравнивают с данными группы, на которой получены нормы. Что прежде всего нужно проверить для такого сравнения?

## Варианты

1. Пригодность этой нормативной группы для цели оценки
2. Одинаковость правил проведения теста при получении всех результатов
3. Устойчивость результатов участника при повторном прохождении теста
4. Связность ответов на пункты одной шкалы в обследованной выборке

## Ответ и пояснение

Пригодность этой нормативной группы для цели оценки

Нормы описывают результаты определённой группы. Нужно знать её состав и условия получения данных и обосновать пригодность сравнения для данного участника и цели. Нормирование отличается от единых правил проведения и подсчёта; необычный результат сам по себе не устанавливает расстройство.
