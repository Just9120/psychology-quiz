# Деятельность, действие и операция

В подходе Леонтьева деятельность соотнесена с мотивом, действие — с осознанной целью, операция — со способом выполнения в определённых условиях. Один результат можно достигать разными способами. Уровни могут переходить друг в друга: деятельность, утратившая свой мотив, может стать действием другой деятельности.

Внешний вид движения и число повторений сами по себе не определяют уровень; по одному поступку нельзя автоматически установить мотив.
