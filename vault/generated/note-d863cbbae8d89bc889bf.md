# Психические свойства

Психические свойства — устойчивые индивидуально-психологические особенности, связанные с постоянными способами взаимодействия человека с миром. В проверенном учебном фрагменте названы темперамент, характер и способности.

Устойчивость здесь не следует понимать как неизменность личности навсегда. Для различения свойств и актов деятельности см. [[note-d8568a4940e53567abb1|психические процессы]].
