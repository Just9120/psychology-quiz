# Критерий сравнения в речи

Слова «лучше», «хуже» или «самый успешный» оставляют открытым критерий сравнения. Для понимания полезно выяснить, с чем сравнивают, по какому признаку и для какой цели. Уточнение критерия помогает обсуждать оценку без навязывания своего стандарта.

## Связи

- [[Операциональное определение]] — делает выбранный признак наблюдаемым
- [[Открытый вопрос]] — помогает выяснить собственный критерий человека
