# Какие данные помогут увидеть нехватку средств между нерегулярными поступлениями дохода?

[[topic-bc06c79f8de325e7d591|Бонусный урок. Личные финансы для помогающего практика]]


## Вопрос

Какие данные помогут увидеть нехватку средств между нерегулярными поступлениями дохода?

## Варианты

1. Даты ожидаемых поступлений и сроки предстоящих платежей
2. Только общую сумму дохода без учёта дат поступления денег
3. Только число клиентов без сумм и сроков оплаченных встреч
4. Лишь предполагаемый годовой доход без ближайших расходов

## Ответ и пояснение

Даты ожидаемых поступлений и сроки предстоящих платежей

При нерегулярном доходе важны и суммы, и сроки: платежи могут наступить раньше следующего поступления денег. Сопоставление ожидаемых поступлений с предстоящими расходами помогает увидеть такой промежуток. Это учебное планирование денежных потоков, без гарантий дохода и рекомендаций по кредитам или инвестициям.
