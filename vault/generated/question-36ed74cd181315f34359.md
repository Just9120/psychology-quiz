# В учебном примере случайно выбирают школы, затем классы, затем учеников внутри выбранных классов. Какой дизайн описан?

[[topic-b05748c075315b416e77|Выборка в психологическом исследовании]]


## Вопрос

В учебном примере случайно выбирают школы, затем классы, затем учеников внутри выбранных классов. Какой дизайн описан?

## Варианты

1. Многоступенчатый кластерный отбор
2. Простой случайный отбор из списка всех учеников
3. Систематический отбор по единому интервалу
4. Квотный отбор по заранее заданным категориям

## Ответ и пояснение

Многоступенчатый кластерный отбор

Сначала выбирают группы, затем единицы внутри них на следующих ступенях. Это многоступенчатый кластерный дизайн. Его нельзя автоматически анализировать как простой случайный отбор всех учеников: возможную зависимость внутри групп учитывают отдельно.
