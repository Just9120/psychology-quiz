# Какую связь между биологическими потребностями и врождёнными программами описывает фрагмент курса по ВНД?

[[topic-1bbf039f694a506dc75b|Лекция 1. Основные понятия физиологии ВНД]]


## Вопрос

Какую связь между биологическими потребностями и врождёнными программами описывает фрагмент курса по ВНД?

## Варианты

1. Потребность обозначает только внешний сигнал, на который направлена реакция
2. Программы связаны с удовлетворением потребностей, например пищевых и безопасности
3. Потребность обозначает только результат уже освоенного условного навыка
4. Программы различаются только по названию сенсорного органа

## Ответ и пояснение

Программы связаны с удовлетворением потребностей, например пищевых и безопасности

В выбранном фрагменте врождённые программы соотносятся с биологическими потребностями, которым они служат: например, с питанием или безопасностью. Потребность не тождественна отдельному внешнему сигналу, выученному навыку или сенсорному органу. Это учебное различение не определяет все мотивы конкретного человека.
