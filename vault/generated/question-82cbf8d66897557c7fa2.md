# В исследовании программы тайм-менеджмента экспериментальную группу набрали из студентов с низкой успеваемостью, контрольную — из студентов с высокой. Какая угроза внутренней валидности наиболее вероятна?

[[topic-c4e7937e5e46d42fae67|Экспериментальные планы исследований]]


## Вопрос

В исследовании программы тайм-менеджмента экспериментальную группу набрали из студентов с низкой успеваемостью, контрольную — из студентов с высокой. Какая угроза внутренней валидности наиболее вероятна?

## Варианты

1. Селективные различия между группами до начала вмешательства
2. Случайная ошибка измерения из-за большого объёма выборки
3. Слишком высокая внешняя валидность из-за неоднородной выборки
4. Эффект плацебо, вызванный двойным ослеплением

## Ответ и пояснение

Селективные различия между группами до начала вмешательства

Группы изначально неэквивалентны по важному признаку, поэтому различия после вмешательства могут быть не его эффектом.
