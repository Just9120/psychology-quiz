# Дедуктивное рассуждение

В дедуктивном рассуждении частный вывод получают из общих положений по правилам логики. Корректный переход не делает исходные посылки истинными автоматически. Поэтому нужно отдельно проверять форму вывода и основания принятых положений.

## Связи

- [[Индуктивное рассуждение]] — имеет другое направление построения вывода
- [[Проверяемая гипотеза]] — помогает исследовать содержательные основания посылок

## Основание

- Лекция 7. Мышление
