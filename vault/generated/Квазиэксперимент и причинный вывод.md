# Квазиэксперимент и причинный вывод

Квазиэксперимент может давать ценные данные, но без случайного распределения участников сложнее исключить альтернативные объяснения. Причинный вывод требует осторожной интерпретации и дополнительных контролей. Название дизайна само по себе не делает данные бесполезными или причинное объяснение доказанным.

## Связи

- [[Случайное распределение по условиям]] — Помогает уменьшать исходные различия групп.
- [[Альтернативное объяснение]] — Требует проверки при интерпретации результата.

## Основание

- Экспериментальные планы исследований
