# Стратифицированный и кластерный отбор

Стратифицированный вероятностный отбор проводится внутри каждой страты; наличие пропорций категорий само по себе не доказывает случайности отбора. В многоступенчатом кластерном дизайне сначала выбирают группы, затем единицы внутри них. При анализе учитывают возможную зависимость внутри групп.

Непропорциональный набор редкой группы меняет доли групп в выборке. Для общей оценки учитывают дизайн и при необходимости веса; взвешивание не устраняет все ошибки измерения и неответы.
