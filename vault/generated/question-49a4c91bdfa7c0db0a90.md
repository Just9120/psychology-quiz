# Когда предпочтения клиента следует учитывать при выборе методов?

[[topic-d0224919faa4f8b42df9|Урок 7. Работа с проблемой и целями. Стратегии и методы консультирования]]


## Вопрос

Когда предпочтения клиента следует учитывать при выборе методов?

## Варианты

1. Только если клиент просит самый директивный формат
2. Когда они не противоречат компетентности консультанта, этике и доказательной опоре метода
3. Всегда буквально, даже если клиент просит небезопасную практику
4. Никогда, потому что метод выбирает только консультант

## Ответ и пояснение

Когда они не противоречат компетентности консультанта, этике и доказательной опоре метода

Предпочтения клиента важны для сотрудничества, но консультант сохраняет профессиональные, этические и доказательные границы.
