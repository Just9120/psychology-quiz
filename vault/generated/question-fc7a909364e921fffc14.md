# Консультант даёт домашнее задание: «Каждый день по два часа выполняйте сложный анализ всех конфликтов», хотя клиент перегружен и сомневается, что справится. Какой принцип нарушен?

[[topic-d0224919faa4f8b42df9|Урок 7. Работа с проблемой и целями. Стратегии и методы консультирования]]


## Вопрос

Консультант даёт домашнее задание: «Каждый день по два часа выполняйте сложный анализ всех конфликтов», хотя клиент перегружен и сомневается, что справится. Какой принцип нарушен?

## Варианты

1. Задание достаточно подробно описать, не уточняя возможности его выполнения
2. Домашнее задание должно быть реалистичным, согласованным с клиентом и связанным с целью
3. Нагрузку задания следует определять по его сложности для консультанта
4. Объём задания следует сохранять до конца работы, даже если он непосилен

## Ответ и пояснение

Домашнее задание должно быть реалистичным, согласованным с клиентом и связанным с целью

В учебной схеме домашнее задание согласуют с клиентом, связывают с целью и учитывают его возможности. Невыполнение обсуждают, а не используют для обвинения; эффективность конкретного задания этим не гарантируется.
