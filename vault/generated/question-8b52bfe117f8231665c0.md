# Какой пример содержит наблюдение, которое можно проверить по записи встречи, а не только интерпретацию?

[[topic-eec9d643c22879fd1ad6|Практика №1]]


## Вопрос

Какой пример содержит наблюдение, которое можно проверить по записи встречи, а не только интерпретацию?

## Варианты

1. Клиент не мотивирован к изменениям
2. У клиента пассивно-агрессивный характер
3. Человек специально провоцирует конфликт
4. На третьем занятии клиент трижды прервал рассказ и сменил тему

## Ответ и пояснение

На третьем занятии клиент трижды прервал рассказ и сменил тему

Факт — это наблюдаемое и фиксируемое событие; остальные варианты содержат объяснения и выводы.
