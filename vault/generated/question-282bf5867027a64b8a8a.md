# В схеме pretest-posttest с заметным выбыванием участников какой риск наиболее критичен?

[[topic-c4e7937e5e46d42fae67|Экспериментальные планы исследований]]


## Вопрос

В схеме pretest-posttest с заметным выбыванием участников какой риск наиболее критичен?

## Варианты

1. Выбывание снижает размер выборки, но не влияет на выводы при любых условиях
2. Селективный dropout может исказить оценку эффекта, если из разных условий систематически выбывают участники с разной динамикой
3. Любое выбывание автоматически делает исследование квазиэкспериментом
4. Проблема выбывания касается только внешней валидности и не затрагивает внутреннюю

## Ответ и пояснение

Селективный dropout может исказить оценку эффекта, если из разных условий систематически выбывают участники с разной динамикой

Если чаще выбывают участники с худшей динамикой, итоговые результаты могут быть систематически смещены.
