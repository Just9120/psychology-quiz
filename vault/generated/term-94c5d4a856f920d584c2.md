# Тип ВНД

Тип ВНД описывается через свойства нервных процессов: силу, уравновешенность и подвижность.

## Примеры

- Обсуждая павловскую типологию, исследователь сопоставляет свойства нервных процессов по серии наблюдений. По короткой беседе нельзя достоверно назначить человеку тип ВНД.

Другие названия: тип высшей нервной деятельности, тип ВНД.
