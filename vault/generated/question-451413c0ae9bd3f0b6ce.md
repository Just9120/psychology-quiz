# Почему утверждение «ты ленивый» по итогам одной тяжелой недели методологически слабое?

[[topic-bb6265d710b5e3e41401|Лекция 3. Психические состояния и личность]]


## Вопрос

Почему утверждение «ты ленивый» по итогам одной тяжелой недели методологически слабое?

## Варианты

1. Потому что усталость нельзя наблюдать
2. Потому что свойства личности не проявляются в поведении
3. Потому что из кратковременного состояния некорректно сразу выводить устойчивое свойство
4. Потому что в психологии не используют описание поведения

## Ответ и пояснение

Потому что из кратковременного состояния некорректно сразу выводить устойчивое свойство

Одна ситуация с утомлением или сниженной активностью не дает оснований надежно приписывать устойчивую черту личности.
