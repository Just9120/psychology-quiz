# В учебном примере значения признака у участников близки, без выраженных подгрупп и выбросов. Когда среднее меньше скрывает индивидуальные различия?

[[topic-e29a5ff50c09f26fe7eb|Практика №8]]


## Вопрос

В учебном примере значения признака у участников близки, без выраженных подгрупп и выбросов. Когда среднее меньше скрывает индивидуальные различия?

## Варианты

1. Когда разброс значений действительно невелик по сравнению с ситуацией сильной неоднородности
2. Когда исследователь вообще не измеряет индивидуальные различия
3. Когда речь идёт только о самых субъективных и разнотипных личностных феноменах
4. Когда выборка слишком мала для каких-либо выводов

## Ответ и пояснение

Когда разброс значений действительно невелик по сравнению с ситуацией сильной неоднородности

При небольшом разбросе среднее меньше скрывает различия между наблюдениями. Нельзя отсюда заключать, что когнитивные показатели вообще мало различаются у всех людей; разброс проверяют по данным.
