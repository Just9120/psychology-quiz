# Если поток стимулов превышает ресурсы обработки, наиболее вероятный эффект:

[[topic-7d097321660cc4a4b4e8|Лекция 10. Фильтрация информации и теории внимания]]


## Вопрос

Если поток стимулов превышает ресурсы обработки, наиболее вероятный эффект:

## Варианты

1. Приоритетная задача теряет ресурс раньше менее важных независимо от распределения
2. Возрастает риск ошибок отбора и снижения качества контроля выполнения
3. Вторая задача получает ту же точность без изменения распределения возможностей
4. Добавление конкурирующего задания само по себе увеличивает доступную ёмкость обработки

## Ответ и пояснение

Возрастает риск ошибок отбора и снижения качества контроля выполнения

По ресурсной модели, при превышении доступных возможностей возрастает риск ошибок; приоритетная задача может сохраняться лучше менее важной. Сохранение всей точности и увеличение ёмкости от одного добавления задачи не следуют из модели. Результат зависит от требований и распределения внимания, а не устанавливается как неизбежный для каждого человека.
