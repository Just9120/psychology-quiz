# Какой порядок стадий консультативного процесса соответствует уроку 3?

[[topic-d761bf5d23372687881d|Урок 3. Структура и процесс консультирования. Навыки первичной консультации]]


## Вопрос

Какой порядок стадий консультативного процесса соответствует уроку 3?

## Варианты

1. Исследование проблемы → двумерное определение желаемого результата → разработка альтернатив → обобщение и переход к действию
2. Определение желаемого результата → исследование проблемы → разработка альтернатив → обобщение и переход к действию
3. Исследование проблемы → разработка альтернатив → определение желаемого результата → обобщение и переход к действию
4. Исследование проблемы → определение желаемого результата → переход к действию → разработка альтернатив

## Ответ и пояснение

Исследование проблемы → двумерное определение желаемого результата → разработка альтернатив → обобщение и переход к действию

Урок описывает эмоциональную и рациональную стороны желаемого результата, поиск альтернатив и согласование шагов. Стадии служат ориентиром и могут перекликаться; схема не объявлена обязательной для всех подходов.
