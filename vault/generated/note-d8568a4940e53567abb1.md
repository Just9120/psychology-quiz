# Психические процессы

Психические процессы — акты психической деятельности, имеющие объект отражения и регуляционную функцию. Это определение относится к деятельности, а не к устойчивым индивидуальным особенностям.

Примеры из того же учебного глоссария вынесены в [[note-f90c39a47e6476f0bfb9|отдельную заметку]]. Для сопоставления категорий см. [[note-d863cbbae8d89bc889bf|психические свойства]].
