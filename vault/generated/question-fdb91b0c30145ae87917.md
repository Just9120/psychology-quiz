# Какое сравнение верно для причинных выводов?

[[topic-c4e7937e5e46d42fae67|Экспериментальные планы исследований]]


## Вопрос

Какое сравнение верно для причинных выводов?

## Варианты

1. Корреляционное исследование сильнее квазиэксперимента
2. Квазиэксперимент сильнее истинного эксперимента из-за реалистичности
3. Истинный эксперимент обычно дает наиболее сильные причинные выводы благодаря рандомизации
4. Все три подхода равны по причинной строгости

## Ответ и пояснение

Истинный эксперимент обычно дает наиболее сильные причинные выводы благодаря рандомизации

Рандомизация и контроль в истинном эксперименте лучше исключают альтернативные объяснения.
