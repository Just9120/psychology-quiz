# Что необходимо клетке для непосредственного распознавания сигнала определённого гормона?

[[topic-aab49399230740a87da6|Лекция 2. Эндокринная система]]


## Вопрос

Что необходимо клетке для непосредственного распознавания сигнала определённого гормона?

## Варианты

1. Подходящий рецептор для этого гормона
2. Расположение рядом с железой независимо от рецепторов
3. Самостоятельная выработка этого же гормона
4. Доставка гормона кровью независимо от рецепторов

## Ответ и пояснение

Подходящий рецептор для этого гормона

Для непосредственного распознавания нужен подходящий рецептор на поверхности или внутри клетки. Доставка гормона кровью и близость к железе не заменяют рецептор; клетка-мишень не обязана сама вырабатывать этот гормон. Вопрос касается непосредственного сигнала, а не возможных косвенных влияний через другие клетки.
