# В исследовании снижения тревоги из интервенционной группы выбыло 35% участников, из контрольной — 5%. Какой основной риск для причинной интерпретации возникает в первую очередь?

[[topic-c4e7937e5e46d42fae67|Экспериментальные планы исследований]]


## Вопрос

В исследовании снижения тревоги из интервенционной группы выбыло 35% участников, из контрольной — 5%. Какой основной риск для причинной интерпретации возникает в первую очередь?

## Варианты

1. Различающийся отсев может изменить состав оставшихся и сместить сравнение групп
2. Разница потерь сама по себе подтверждает преимущество интервенции
3. Рандомизация на старте гарантирует сопоставимость групп после любых потерь
4. Анализ оставшихся автоматически представляет результат всех исходных участников

## Ответ и пояснение

Различающийся отсев может изменить состав оставшихся и сместить сравнение групп

Разница в доле выбывших указывает на риск: причины ухода и характеристики оставшихся требуют проверки. Проценты сами по себе не доказывают селективность или реальное изменение состава. Стартовая рандомизация и анализ завершивших не устраняют этот вопрос автоматически.
