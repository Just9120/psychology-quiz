# Интериоризация нормы

Интериоризация в данном объяснении — переход внешней социальной нормы во внутренний регулятор. Определение описывает процесс, но не раскрывает все мотивы конкретного человека. Соблюдение правила без наблюдателя само по себе не устанавливает причин поведения.
