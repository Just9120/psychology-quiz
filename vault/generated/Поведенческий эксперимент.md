# Поведенческий эксперимент

Поведенческий эксперимент проверяет прогноз или убеждение через запланированное действие и последующий анализ. Это один из когнитивно-поведенческих инструментов. Знакомство с ним не определяет лечение по одному симптому.

## Связи

- [[Проверка консультативной гипотезы]] — Проверка требует различать ожидание и наблюдаемый результат.
- [[Работа между встречами]] — Запланированное действие может быть согласовано для выполнения вне беседы.
