# Почему среднее по группе не всегда достаточно для полноценного вывода об эффективности интервенции?

[[topic-e29a5ff50c09f26fe7eb|Практика №8]]


## Вопрос

Почему среднее по группе не всегда достаточно для полноценного вывода об эффективности интервенции?

## Варианты

1. Потому что групповые данные в психологии бесполезны
2. Потому что среднее запрещено использовать в гуманитарных науках
3. Потому что индивидуальные различия всегда важнее любого общего эффекта
4. Среднее может скрывать различия индивидуального отклика

## Ответ и пояснение

Среднее может скрывать различия индивидуального отклика

Групповое среднее полезно для описания общей тенденции, но одинаковая средняя величина может сопровождаться разными индивидуальными результатами. Поэтому при интерпретации полезно учитывать распределение откликов; среднее не доказывает одинаковую пользу для каждого участника.
