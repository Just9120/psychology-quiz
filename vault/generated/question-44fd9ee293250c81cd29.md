# Исследователь сравнивает целевую интервенцию с другой организованной активностью. Для чего может быть полезен такой контроль?

[[topic-e29a5ff50c09f26fe7eb|Практика №8]]


## Вопрос

Исследователь сравнивает целевую интервенцию с другой организованной активностью. Для чего может быть полезен такой контроль?

## Варианты

1. Чтобы отнести любое улучшение в обеих группах к изучаемому механизму
2. Чтобы считать разные активности сопоставимыми по всем условиям без проверки
3. Чтобы оценить эффект изучаемой интервенции только по изменению её группы
4. Чтобы сравнить результаты целевой интервенции и другой организованной активности

## Ответ и пояснение

Чтобы сравнить результаты целевой интервенции и другой организованной активности

Активный контроль даёт сравнение с другой деятельностью. Для интерпретации нужно обосновать сопоставимость условий: разные программы могут отличаться по нескольким признакам. Улучшение одной или обеих групп не устанавливает единственный механизм эффекта.
