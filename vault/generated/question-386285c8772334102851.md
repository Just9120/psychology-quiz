# Можно ли по одной фразе клиента «В знакомой ситуации снова делаю по-старому» установить, что причиной поведения является динамический стереотип?

[[topic-1bbf039f694a506dc75b|Лекция 1. Основные понятия физиологии ВНД]]


## Вопрос

Можно ли по одной фразе клиента «В знакомой ситуации снова делаю по-старому» установить, что причиной поведения является динамический стереотип?

## Варианты

1. Нет: учебная модель не устанавливает индивидуальную причину по одной фразе
2. Да: любая повторная реакция однозначно подтверждает этот механизм
3. Да: понимание правила исключает все другие объяснения поведения
4. Нет: прежний опыт вообще не может участвовать в поведении

## Ответ и пояснение

Нет: учебная модель не устанавливает индивидуальную причину по одной фразе

Динамический стереотип в курсе описывает устойчивую последовательность условных реакций. Модель может помочь сформулировать вопрос, но отдельный рассказ не устанавливает физиологическую причину поведения конкретного человека.
