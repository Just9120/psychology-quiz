# Что лучше всего повышает переносимость (transferability) качественных результатов?

[[topic-3b48974a9d90e146c3b2|Практика №12]]


## Вопрос

Что лучше всего повышает переносимость (transferability) качественных результатов?

## Варианты

1. Максимально краткое описание контекста исследования
2. Увеличение выборки без описания процедуры
3. Сокрытие критериев отбора участников
4. Подробное thick description контекста, участников и условий

## Ответ и пояснение

Подробное thick description контекста, участников и условий

Подробное описание контекста позволяет читателю оценить применимость выводов к другим условиям.
