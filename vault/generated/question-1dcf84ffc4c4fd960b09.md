# Нарушение какой функции связано с понятием апраксии в лекции?

[[topic-4c3daeba5e9cb0e03262|Нейропсихология: мозг и когнитивные функции]]


## Вопрос

Нарушение какой функции связано с понятием апраксии в лекции?

## Варианты

1. Выполнения освоенных целенаправленных действий
2. Только понимания значения слов в устном сообщении
3. Только узнавания предметов при сохранном зрении
4. Произвольного движения исключительно из-за слабости мышц

## Ответ и пояснение

Выполнения освоенных целенаправленных действий

Апраксия связана с нарушением выполнения освоенных целенаправленных действий. Её не сводят к мышечной слабости, непониманию задания или незнакомству с действием. Для клинического вывода нужна оценка этих и других возможных объяснений; одна неудача в задании не устанавливает диагноз.
