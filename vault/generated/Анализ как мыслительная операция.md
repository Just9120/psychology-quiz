# Анализ как мыслительная операция

Анализ — мысленное выделение частей и характеристик рассматриваемого объекта. Он позволяет уточнить, из каких компонентов складывается задача. Выделенные части нужно затем соотнести с целым: сам перечень признаков ещё не объясняет работу системы.

- [[Мышление]] — включает операции работы с задачей
