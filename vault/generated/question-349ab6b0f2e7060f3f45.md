# Какой признак отличает структурированное интервью при подборе персонала в описании курса?

[[topic-84d922168a9be117642c|Анализ деятельности и профессиография. Подбор и оценка персонала]]


## Вопрос

Какой признак отличает структурированное интервью при подборе персонала в описании курса?

## Варианты

1. Заранее подготовленные вопросы, которые задают кандидатам по общей схеме
2. Свободная беседа, содержание которой полностью зависит от первого впечатления
3. Самостоятельное заполнение анкеты без разговора с интервьюером
4. Выбор разных тем для каждого кандидата без заранее заданного плана

## Ответ и пояснение

Заранее подготовленные вопросы, которые задают кандидатам по общей схеме

Курс описывает структурированное интервью как собеседование с заранее подготовленным набором вопросов и общей схемой для кандидатов. Такая организация отличается от полностью свободной беседы. Она не означает, что одной встречи достаточно для безошибочного кадрового решения: нужны требования работы и обоснованная оценка ответов.
