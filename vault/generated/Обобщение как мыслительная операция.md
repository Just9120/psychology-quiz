# Обобщение как мыслительная операция

Обобщение объединяет объекты в категорию по выбранным признакам. Для оценки обобщения важно знать основание отбора и исключения. Сходство нескольких примеров не устанавливает универсального правила для всех объектов категории.

## Связи

- [[Абстрагирование]] — выделяет признаки, по которым строится категория
- [[Пределы обобщения результата]] — ограничивает перенос вывода за исследованные условия
- [[Обобщение в высказывании]] — описывает соответствующий способ речевого представления опыта

## Основание

- Лекция 7. Мышление
