# Школьное благополучие в наблюдательных данных

Отчёт PISA 2018 Volume III рассматривает школьный опыт и благополучие учащихся с помощью исторических наблюдательных данных. Важно различать описания групп, самоотчёты и причинное объяснение. Связь школьного фактора с показателем благополучия не устанавливает эффект изменения этого фактора для каждого ученика.
