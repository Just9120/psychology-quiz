# Как консультанту поддержать выбор клиента, который просит решить за него?

Точная тема не установлена; предметная область: Кейс.

## Ситуация

Вымышленный взрослый клиент выбирает между двумя предложениями работы. У каждого варианта есть преимущества и ограничения. Он говорит: «Скажите, какой выбрать, и я так сделаю».

Подход: Поддержка самостоятельного решения через исследование вариантов и последствий

### Условия

- Признаки срочной опасности не описаны
- Клиент способен обсуждать варианты; вопрос не касается медицинского или юридического решения

## Вопрос

Как консультанту поддержать выбор клиента, который просит решить за него?

## Варианты

1. Помочь сравнить варианты с важными для клиента условиями, оставив окончательное решение за ним
2. Рекомендовать предложение с большей зарплатой, поскольку оно объективно лучше для любого клиента
3. Передать выбор близкому клиента, поскольку консультант не должен принимать решение
4. Отказаться обсуждать последствия вариантов, чтобы никак не влиять на самостоятельность клиента

## Ответ и пояснение

Помочь сравнить варианты с важными для клиента условиями, оставив окончательное решение за ним

Консультант может поддерживать исследование вариантов, ценностей и последствий, не принимая жизненное решение вместо клиента. Самостоятельность не означает отсутствия помощи; зарплата или мнение близкого сами по себе не определяют подходящий вариант.

### Почему другие варианты не подходят

1. Совместное сравнение помогает клиенту сделать собственный выбор и не снимает профессиональной ответственности с консультанта.
2. Большая зарплата — лишь один критерий; важные для клиента условия пока различаются.
3. Передача решения другому человеку не поддерживает участие клиента в собственном выборе.
4. Обсуждать варианты допустимо: самостоятельность клиента не требует отказа от консультативной поддержки.

### Границы вывода

Если появятся иные существенные обстоятельства, их нужно учесть. Этот пример не переносится автоматически на ситуации, требующие срочного обеспечения безопасности или специальной профессиональной консультации.
