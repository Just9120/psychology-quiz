# В учебной задаче результат скринингового опросника указывает на возможные признаки депрессии. Что можно заключить из одного такого результата?

[[topic-fc06e6c8137fa10ad86c|Практика №17. Первая встреча]]


## Вопрос

В учебной задаче результат скринингового опросника указывает на возможные признаки депрессии. Что можно заключить из одного такого результата?

## Варианты

1. Есть основание для дальнейшей оценки; один результат не устанавливает диагноз
2. Диагноз уже окончательно установлен, дополнительные сведения больше не нужны
3. Причина состояния уже определена, поэтому можно сразу выбрать любое лечение
4. Отрицательный результат другого теста автоматически отменит все жалобы человека

## Ответ и пояснение

Есть основание для дальнейшей оценки; один результат не устанавливает диагноз

Скрининг помогает заметить возможные признаки и определить необходимость дальнейшей оценки. Для диагностики учитывают дополнительные сведения и подходящие обследования; единственный балл опросника не заменяет этот процесс. Здесь не задаются пороги, лечение или правила оценки конкретного человека.
