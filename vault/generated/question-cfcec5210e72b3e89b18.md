# В деятельностном разборе личности в курсе человек оценивает действие только по тому, приятно ли оно ему. Какое дополнение к этой оценке выделяет лектор?

[[topic-bec9f523fe130e941bea|Личность в психологии]]


## Вопрос

В деятельностном разборе личности в курсе человек оценивает действие только по тому, приятно ли оно ему. Какое дополнение к этой оценке выделяет лектор?

## Варианты

1. Учёт последствий действия для других людей
2. Учёт только длительности собственного удовольствия
3. Учёт только числа уже выполненных действий
4. Учёт только скорости выполнения выбранного действия

## Ответ и пояснение

Учёт последствий действия для других людей

В этом разборе выделяют последствия действия для других людей наряду с его значением для самого действующего. Это позиция рассматриваемого подхода. Она не задаёт универсальную шкалу личности и не позволяет оценивать нравственность человека по одному поступку или одной реплике.
