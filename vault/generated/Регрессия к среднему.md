# Регрессия к среднему

При отборе крайних значений повторные результаты могут приблизиться к среднему без реального эффекта интервенции. Например, отбор исключительно самых высоких исходных показателей требует учитывать этот механизм при интерпретации последующего снижения.

## Связи

- [[Повторные измерения]] — Изменение между замерами не доказывает причинность.
- [[Альтернативное объяснение]] — Приближение к среднему является одной из возможных причин.

## Основание

- Экспериментальные планы исследований
