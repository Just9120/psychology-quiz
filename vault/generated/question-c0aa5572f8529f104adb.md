# Какой из вариантов описывает когнитивно-поведенческий инструмент, изучаемый в уроке, без назначения лечения конкретному клиенту?

[[topic-d0224919faa4f8b42df9|Урок 7. Работа с проблемой и целями. Стратегии и методы консультирования]]


## Вопрос

Какой из вариантов описывает когнитивно-поведенческий инструмент, изучаемый в уроке, без назначения лечения конкретному клиенту?

## Варианты

1. Резюмирование основных тем рассказа перед завершением встречи
2. Обсуждение организационных условий и границ совместной работы
3. Поведенческий эксперимент для проверки согласованного с клиентом предположения
4. Эмпатическое отражение переживаний в рассказе о трудности

## Ответ и пояснение

Поведенческий эксперимент для проверки согласованного с клиентом предположения

Поведенческий эксперимент — один из когнитивно-поведенческих инструментов. Этот вопрос проверяет знакомство с инструментом, а не определяет лечение по одному симптому.
