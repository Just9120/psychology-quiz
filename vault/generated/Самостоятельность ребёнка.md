# Самостоятельность ребёнка

Самостоятельность ребёнка можно рассматривать как меняющуюся сторону взаимодействия при взрослении. Доступные решения соотносят с возможностями ребёнка, ситуацией и безопасностью. Развитие самостоятельности не требует одномоментной отмены всех ограничений; возраст сам по себе не заменяет индивидуальной оценки.

## Связи

- [[Внутренние границы семьи]] — Семейные роли меняются вместе с доступными решениями.
- [[Развитие на протяжении жизни]] — Даёт более широкий контекст изменений.
