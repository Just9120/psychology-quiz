# Контрольное условие

Сравнение с контрольным условием помогает рассмотреть изменения, связанные со временем, тестированием и внешними событиями. Улучшение экспериментальной группы само по себе не устанавливает эффект воздействия. Сходство исходных средних не заменяет планирование сравнения; контроль тоже требует измерений.

## Связи

- [[Активный контроль]] — Использует другую деятельность для сравнения.
- [[Список ожидания]] — Предусматривает отложенное получение воздействия.
- [[Внутренняя валидность]] — Контроль помогает оценивать альтернативные причины.

## Основание

- Экспериментальные планы исследований
