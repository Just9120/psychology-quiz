# Символическое значение объекта

В символическом интеракционизме понимание действия связано со значением, которое человек придаёт объекту. Один предмет может иметь разный смысл в разных обстоятельствах. Теоретическая рамка не сводит всё поведение к единственному механизму.

## Связи

- [[Социальный контекст поведения]] — Значения рассматривают в обстоятельствах взаимодействия.
- [[Самость в теории Мида]] — Усвоение социальных ожиданий участвует в восприятии себя.

## Основание

- Лекция 2. История формирования социально-психологических идей. Часть 3
