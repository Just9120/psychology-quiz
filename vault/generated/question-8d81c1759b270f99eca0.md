# Два вымышленных взрослых клиента разного возраста говорят: «Не понимаю, чего хочу». Какой следующий шаг соответствует учебному разбору возрастных задач?

[[topic-ac877ebd7e3eb940963b|Практика №29. Возрастной контекст запроса]]


## Вопрос

Два вымышленных взрослых клиента разного возраста говорят: «Не понимаю, чего хочу». Какой следующий шаг соответствует учебному разбору возрастных задач?

## Варианты

1. Уточнить контекст каждого и проверить несколько гипотез
2. Выбрать одинаковую технику только по совпадению жалобы
3. Установить кризис каждому только по календарному возрасту
4. Считать одинаковую формулировку доказательством одной причины

## Ответ и пояснение

Уточнить контекст каждого и проверить несколько гипотез

Совпадение жалобы не устанавливает совпадение причин. В разборе предлагается рассматривать актуальные задачи, гипотезы, вопросы и цели консультирования. Их нужно соотносить с фактами отдельной ситуации; возраст помогает формулировать вопросы, но не заменяет выяснение контекста.
