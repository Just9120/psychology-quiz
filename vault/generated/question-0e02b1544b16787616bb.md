# Какой вывод корректно передаёт контраст между элементаризмом и гештальт-подходом?

[[topic-d82c3f854ec664eff100|Предмет и метод психологии]]


## Вопрос

Какой вывод корректно передаёт контраст между элементаризмом и гештальт-подходом?

## Варианты

1. Элементаризм объясняет свойства через организацию целого, гештальт — через сумму элементов
2. Оба подхода считают организацию элементов несущественной для свойств целого
3. Различие состоит только в выборе метода: целостность в обоих подходах понимается одинаково
4. Гештальт выделяет свойства целого, не сводимые к простому суммированию элементов

## Ответ и пояснение

Гештальт выделяет свойства целого, не сводимые к простому суммированию элементов

Контраст относится к объяснению свойств целого: в гештальт-подходе существенна организация. Обратная характеристика меняет подходы местами; игнорирование организации и сведение различия только к методу теряют эту идею. Это историческое концептуальное сравнение.
