# Какую функцию выполняют ионные каналы в мембране нейрона?

[[topic-a6ee909b0d48baacabf7|Анатомия мозга и нейромедиаторы]]


## Вопрос

Какую функцию выполняют ионные каналы в мембране нейрона?

## Варианты

1. Создают путь для прохождения определённых ионов через мембрану
2. Переносят ионы через мембрану за счёт непосредственного расщепления АТФ
3. Упаковывают молекулы медиатора для их последующего выделения из клетки
4. Превращают действие медиатора в синтез внутриклеточного вторичного посредника

## Ответ и пояснение

Создают путь для прохождения определённых ионов через мембрану

Ионный канал образует путь для ионов через мембрану. Работа насоса с непосредственным использованием АТФ, упаковка медиатора в пузырьки и образование вторичных посредников — другие механизмы. Некоторые рецепторы одновременно являются каналами, но это не делает все перечисленные процессы одной функцией.
