# Эксперимент запланирован для проверки конкурирующих теорий в ситуации, где их предсказания расходятся. Это:

[[topic-c4e7937e5e46d42fae67|Экспериментальные планы исследований]]


## Вопрос

Эксперимент запланирован для проверки конкурирующих теорий в ситуации, где их предсказания расходятся. Это:

## Варианты

1. Поисковый (exploratory)
2. Подтверждающий (confirmatory)
3. Критический эксперимент
4. Натуральный эксперимент

## Ответ и пояснение

Критический эксперимент

Критический эксперимент ставят так, чтобы различить альтернативные объяснения/теории.
