# Воображение

Воображение связано с созданием новых образов через переработку прошлого опыта. Например, превращение коробок в космический корабль предполагает новые функции и образ, а не только воспроизведение знакомого. Восприятие, память и мышление могут одновременно участвовать в деятельности.

## Связи

- [[Мышление]] — Может решать конструктивные задачи при создании образа.
- [[Память]] — Сохраняет материал опыта для переработки.

## Основание

- Лекция 2. Психические процессы
