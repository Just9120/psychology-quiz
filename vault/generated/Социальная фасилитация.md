# Социальная фасилитация

Социальная фасилитация описывает улучшение выполнения в присутствии других. Освоенность и сложность задачи имеют значение. Аудитория не улучшает автоматически любое действие; ухудшение выполнения нельзя назвать фасилитацией.

## Связи

- [[Социальный контекст поведения]] — Присутствие других является условием действия.
- [[Пределы обобщения результата]] — Результат освоенной задачи не переносится автоматически на любую задачу.

## Основание

- Лекция 2. История формирования социально-психологических идей. Часть 1
