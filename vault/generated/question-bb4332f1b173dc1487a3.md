# Какой признак необходим для вероятностного отбора из генеральной совокупности?

[[topic-b05748c075315b416e77|Выборка в психологическом исследовании]]


## Вопрос

Какой признак необходим для вероятностного отбора из генеральной совокупности?

## Варианты

1. Известная ненулевая вероятность включения каждого элемента
2. Одинаковый фактический состав любых двух выборок
3. Обязательное участие всех приглашённых респондентов
4. Полное отсутствие ошибок измерения показателя

## Ответ и пояснение

Известная ненулевая вероятность включения каждого элемента

При вероятностном отборе вероятности включения известны и ненулевые. Они не обязаны быть одинаковыми для всех элементов. Это не гарантирует отсутствие ошибок измерения или отказов от участия.
