# Какую задачу презентация связывает с качественной методологией?

[[topic-32ccbd7c82a23a7f69a6|Качественные методы 1]]


## Вопрос

Какую задачу презентация связывает с качественной методологией?

## Варианты

1. Исключительно статистическое объяснение различий между группами
2. Открытие нового и подробное описание целостных случаев
3. Только построение репрезентативной выборки для популяционной оценки
4. Автоматическое кодирование данных без интерпретации

## Ответ и пояснение

Открытие нового и подробное описание целостных случаев

В учебной таблице качественная методология соотнесена с открытием нового и подробным описанием целостных случаев. Это обозначенный в модели акцент, а не единственная допустимая задача качественного исследования.
