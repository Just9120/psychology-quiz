# Как в учебном изложении метода незавершённых предложений для оценки развития эго получают итоговую оценку?

[[topic-2c5b27ecd529982f0c78|Практика №28]]


## Вопрос

Как в учебном изложении метода незавершённых предложений для оценки развития эго получают итоговую оценку?

## Варианты

1. Кодируют набор ответов по установленному руководству
2. Выбирают уровень по первому впечатлению о респонденте
3. Приравнивают возраст респондента к уровню развития
4. Считают любое длинное предложение признаком зрелости

## Ответ и пояснение

Кодируют набор ответов по установленному руководству

В описанном подходе ответы кодируют по специальным правилам руководства, а не по свободному впечатлению. Это требует соответствующей подготовки и выбранной версии процедуры. Учебное описание не даёт права ставить диагноз или оценивать развитие человека по одной реплике, возрасту или длине ответа.
