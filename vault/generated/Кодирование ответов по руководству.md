# Кодирование ответов по руководству

В описанном подходе ответы кодируют по специальным правилам руководства, а не по свободному впечатлению. Нужны подготовка и выбранная версия процедуры. Учебное описание не даёт основания оценивать развитие или ставить диагноз по реплике, возрасту или длине ответа.
