# В учебной схеме между двумя клетками показаны соединяющие каналы, через которые ионы переходят прямо из одной клетки в другую. Как классифицировать этот контакт?

[[topic-26a9462e9d57e3b8f22a|Лекция 1. Нервная система]]


## Вопрос

В учебной схеме между двумя клетками показаны соединяющие каналы, через которые ионы переходят прямо из одной клетки в другую. Как классифицировать этот контакт?

## Варианты

1. Как химический синапс с выделением медиатора в щель
2. Как электрический синапс с прямым переходом ионов
3. Как гормональную передачу сигнала через кровоток
4. Как проведение по одному аксону между перехватами Ранвье

## Ответ и пояснение

Как электрический синапс с прямым переходом ионов

Прямой переход ионов через соединение клеток описывает электрический синапс. Для химического синапса выделяют медиатор, синаптическую щель и рецепторы клетки-мишени. Гормональная передача через кровь и проведение по одному аксону не описывают показанный межклеточный контакт. Вопрос различает схемы передачи, без клинического применения.
