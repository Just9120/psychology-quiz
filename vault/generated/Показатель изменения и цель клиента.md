# Показатель изменения и цель клиента

Оценка изменения в консультировании требует заранее понимать, какой результат значим для клиента и по каким сведениям его можно заметить. Единичное улучшение настроения не исчерпывает долгосрочную цель. Повторная оценка помогает сопоставить субъективное переживание и конкретные изменения жизни.
