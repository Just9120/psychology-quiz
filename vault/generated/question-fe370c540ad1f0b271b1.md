# Человек заметил, что его детство не совпадает с описанной в лекции схемой развития. Какой вывод обоснован только этим сравнением?

[[topic-21d605a9464356d13763|Лекция 1. Введение в возрастную психологию]]


## Вопрос

Человек заметил, что его детство не совпадает с описанной в лекции схемой развития. Какой вывод обоснован только этим сравнением?

## Варианты

1. Есть различие со схемой; для выводов о человеке нужны дополнительные сведения
2. Любое отличие само по себе доказывает нарушение психического развития
3. Несовпадение со схемой точно объясняет все трудности взрослого человека
4. Описание схемы позволяет восстановить пропущенные события его биографии

## Ответ и пояснение

Есть различие со схемой; для выводов о человеке нужны дополнительные сведения

Учебная схема не заменяет сведения о конкретном человеке. Сам факт несовпадения не устанавливает нарушение развития, причину всех текущих трудностей или неизвестные события биографии. Это ограничение вывода по сравнению со схемой; оно не означает, что любые трудности следует игнорировать.
