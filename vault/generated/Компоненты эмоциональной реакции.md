# Компоненты эмоциональной реакции

Эмоциональная реакция может включать субъективное переживание, физиологические изменения и выражение в поведении. Это основание междисциплинарного изучения состояния. Сочетание компонентов не означает, что каждой эмоции соответствует один мозговой центр или что по активации можно поставить диагноз.

## Связи

- [[Мобилизация при нагрузке]] — Один из возможных телесных аспектов значимой ситуации.
- [[Отражение чувств]] — В беседе переживание уточняют, а не устанавливают по одному внешнему признаку.

## Основание

- Лекция 4. Эмоции, принятие решений, воля
