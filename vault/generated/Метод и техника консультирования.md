# Метод и техника консультирования

В учебном различении метод — общее направление работы, техника — конкретные инструменты и шаги внутри него. Различение помогает связать действия с выбранной целью, но не доказывает эффективности любой техники.

## Связи

- [[Выбор метода консультирования]] — Средства выбирают относительно случая и цели.
- [[Поведенческий эксперимент]] — Конкретный инструмент не определяет весь подход.
