# Какая запись по Кэмпбеллу соответствует одно-групповому предтест-посттест дизайну?

[[topic-c4e7937e5e46d42fae67|Экспериментальные планы исследований]]


## Вопрос

Какая запись по Кэмпбеллу соответствует одно-групповому предтест-посттест дизайну?

## Варианты

1. X O
2. O X O
3. R O X O
4. R X O

## Ответ и пояснение

O X O

Для одной группы измерение проводится до и после воздействия: O X O.
