# Какой подход по ресурсной модели может уменьшить конкуренцию задач при многозадачности?

[[topic-7d097321660cc4a4b4e8|Лекция 10. Фильтрация информации и теории внимания]]


## Вопрос

Какой подход по ресурсной модели может уменьшить конкуренцию задач при многозадачности?

## Варианты

1. Повышать число параллельных задач без ограничений
2. Полностью отказаться от пауз
3. Структурировать задачи по приоритету и уменьшать число одновременных каналов
4. Случайно менять цели каждые несколько минут

## Ответ и пояснение

Структурировать задачи по приоритету и уменьшать число одновременных каналов

Приоритизация и уменьшение числа одновременных задач позволяют снизить конкуренцию за внимание. Это способ организации нагрузки, а не гарантия отсутствия ошибок.
