# Повседневные правила взаимодействия

Этнометодологический ракурс обращает внимание на поддержание повседневного взаимодействия с помощью обычно не проговариваемых правил. Ожидания зависят от ситуации и сообщества; нельзя автоматически считать их одинаковыми для всех культур.

## Связи

- [[Социальный контекст поведения]] — Контекст ограничивает перенос ожиданий.
- [[Самопрезентация как драматургическая модель]] — Представление себя соотносится с социальными ожиданиями.

## Основание

- Лекция 2. История формирования социально-психологических идей. Часть 3
