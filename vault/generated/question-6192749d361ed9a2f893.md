# Какую роль обычно выполняет домашнее задание в консультировании?

Точная тема не установлена; предметная область: Психологическое консультирование.


## Вопрос

Какую роль обычно выполняет домашнее задание в консультировании?

## Варианты

1. Определяет причины затруднения по самому факту выполнения задания
2. Помогает переносить изменения из сессии в повседневную жизнь клиента
3. Подтверждает правильность выбранного метода независимо от результата
4. Оценивает качество сотрудничества по объёму выполненных упражнений

## Ответ и пояснение

Помогает переносить изменения из сессии в повседневную жизнь клиента

Домашнее задание поддерживает применение новых способов поведения, мышления или самонаблюдения между встречами.
