# Почему добавление нескольких измерений по ходу интервенции может быть полезнее, чем только одно «до» и одно «после»?

[[topic-e29a5ff50c09f26fe7eb|Практика №8]]


## Вопрос

Почему добавление нескольких измерений по ходу интервенции может быть полезнее, чем только одно «до» и одно «после»?

## Варианты

1. Потому что больше измерений автоматически доказывает причинность
2. Потому что это полностью устраняет необходимость контрольной группы
3. Потому что так можно не учитывать побочные переменные
4. Потому что это помогает лучше увидеть динамику изменений и уменьшить риск слишком грубого вывода по двум точкам

## Ответ и пояснение

Потому что это помогает лучше увидеть динамику изменений и уменьшить риск слишком грубого вывода по двум точкам

Несколько измерений помогают увидеть ход изменений. Они сами по себе не исключают альтернативных причин и не заменяют необходимое сравнение.
