# Декомпозиция цели

Декомпозиция переводит крупную цель в конкретные небольшие и достижимые шаги. Шаг должен сохранять связь с желаемым результатом, а не становиться отдельным требованием без обсуждения с клиентом.

## Связи

- [[Консультативная цель]] — Определяет направление шагов.
- [[Работа между встречами]] — Согласованный шаг может выполняться вне консультации.

## Основание

- Психологическое консультирование — Глоссарий основных понятий
