# В чём ограничение вывода о субъективных мотивах участника только по факту его подчинения в эксперименте?

[[topic-d82c3f854ec664eff100|Предмет и метод психологии]]


## Вопрос

В чём ограничение вывода о субъективных мотивах участника только по факту его подчинения в эксперименте?

## Варианты

1. Он не позволяет регистрировать поведенческие различия между условиями
2. Он исключает возможность межгруппового сравнения
3. Один наблюдаемый поведенческий результат не раскрывает все субъективные смыслы и мотивы человека
4. Он не может давать проверяемые выводы

## Ответ и пояснение

Один наблюдаемый поведенческий результат не раскрывает все субъективные смыслы и мотивы человека

Для вывода о конкретных субъективных мотивах нужны дополнительные данные. Факт подчинения сам по себе не даёт полного объяснения внутреннего опыта; это не означает, что количественные методы вообще не могут изучать мотивы.
