# По какому основанию различаются типы в изложенной в курсе типологии Шпрангера?

[[topic-d1a06ab0000462e7654e|Лекция 6. Личностные типы и структура индивидуальности]]


## Вопрос

По какому основанию различаются типы в изложенной в курсе типологии Шпрангера?

## Варианты

1. По преобладающим ценностным ориентациям
2. По особенностям телосложения и конституции
3. По динамическим характеристикам темперамента
4. По выраженности факторов личностного опросника

## Ответ и пояснение

По преобладающим ценностным ориентациям

В изложении типологии Шпрангера основание различения — ценности и жизненные ориентиры. Это историческая типологическая модель. Она не даёт готового диагноза, не требует относить человека только к одному типу и не устанавливает его способности по первому впечатлению.
