# Как поступить с рабочей гипотезой, если новые сведения ей противоречат?

Точная тема не установлена; предметная область: Кейс.

## Ситуация

Вымышленный взрослый клиент тревожится перед командными встречами. Консультант предположил страх оценки коллег. Клиент уточняет, что обсуждения оценок переносит спокойно, а напряжение возникает только при неожиданной смене повестки.

Подход: Пересмотр предварительной концептуализации по новым данным

### Условия

- Причина тревоги ещё не установлена; гипотеза была предварительной
- Новые сведения доступны для совместного обсуждения, срочной ситуации нет

## Вопрос

Как поступить с рабочей гипотезой, если новые сведения ей противоречат?

## Варианты

1. Сохранить гипотезу как факт, поскольку её сформулировал консультант
2. Сразу заменить гипотезу диагнозом, объясняющим реакцию на смену повестки
3. Уточнить конкретные эпизоды и пересмотреть гипотезу с учётом новой информации
4. Отложить противоречащие сведения до конца работы, чтобы не менять первоначальный план

## Ответ и пояснение

Уточнить конкретные эпизоды и пересмотреть гипотезу с учётом новой информации

Рабочая гипотеза должна проверяться и уточняться по поступающим сведениям. Новое описание делает первоначальную версию менее убедительной и требует сопоставления с эпизодами. Авторитет консультанта не превращает предположение в факт, а данных для диагноза здесь нет.

### Почему другие варианты не подходят

1. Авторство гипотезы не подтверждает её соответствия опыту клиента.
2. Одно уточнение обстоятельств не даёт достаточного основания для диагноза.
3. Ответ позволяет сопоставить версию с фактами и уточнить объяснение без подгонки данных.
4. Игнорирование существенного противоречия препятствует проверке исходной версии.

### Границы вывода

Новые сведения не обязательно сразу опровергают всю версию и не доказывают единственную другую причину. Нужно проверить различия между эпизодами и сохранить предварительный характер объяснения.
