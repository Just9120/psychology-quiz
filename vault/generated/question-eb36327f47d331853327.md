# Какова главная задача стадии разработки альтернатив?

[[topic-d761bf5d23372687881d|Урок 3. Структура и процесс консультирования. Навыки первичной консультации]]


## Вопрос

Какова главная задача стадии разработки альтернатив?

## Варианты

1. Расширить поле зрения клиента и помочь увидеть несколько возможных способов действия
2. Выбрать за клиента единственно правильное решение
3. Доказать, что прежние действия клиента были бессмысленны
4. Заменить исследование проблемы моральной оценкой поведения

## Ответ и пояснение

Расширить поле зрения клиента и помочь увидеть несколько возможных способов действия

Разработка альтернатив помогает клиенту увидеть варианты и последствия, сохраняя его авторство выбора.
