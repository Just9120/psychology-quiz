# В павловском учебном примере формирование нового навыка прерывается сильным посторонним стимулом. Какое наблюдение соответствует внешнему торможению?

[[topic-1bbf039f694a506dc75b|Лекция 1. Основные понятия физиологии ВНД]]


## Вопрос

В павловском учебном примере формирование нового навыка прерывается сильным посторонним стимулом. Какое наблюдение соответствует внешнему торможению?

## Варианты

1. Ослабление выполнения текущей реакции при отвлечении
2. Усиление реакции вследствие её очередного подкрепления
3. Исчезновение реакции после повторений сигнала без подкрепления
4. Сохранение реакции на один из двух сходных подкрепляемых сигналов

## Ответ и пояснение

Ослабление выполнения текущей реакции при отвлечении

Внешнее торможение в выбранном описании связано с посторонним воздействием, мешающим текущей задаче. Его отличают от подкрепления, угасания и дифференцировки. Один факт отвлечения не является диагнозом; пример показывает условия торможения в исторической модели.
