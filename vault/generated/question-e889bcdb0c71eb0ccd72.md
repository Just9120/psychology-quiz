# Какую задачу факторного анализа описывает выбранный учебный фрагмент?

[[topic-2c5b27ecd529982f0c78|Практика №28]]


## Вопрос

Какую задачу факторного анализа описывает выбранный учебный фрагмент?

## Варианты

1. Выявлять общую структуру связей между показателями
2. Проверять различие средних показателя в сравниваемых группах
3. Группировать участников по сходству их наблюдаемых показателей
4. Оценивать связь одного показателя с набором предикторов

## Ответ и пояснение

Выявлять общую структуру связей между показателями

В выбранном объяснении факторный анализ помогает обнаруживать общие структуры в связях между показателями. Такая структура не доказывает сама по себе причинного механизма, клинического диагноза или единственно возможной модели личности.
