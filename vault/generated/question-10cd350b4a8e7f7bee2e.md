# Для чего в межгрупповом исследовании сравнивают экспериментальную группу с контрольной?

[[topic-c4e7937e5e46d42fae67|Экспериментальные планы исследований]]


## Вопрос

Для чего в межгрупповом исследовании сравнивают экспериментальную группу с контрольной?

## Варианты

1. Чтобы считать любое изменение экспериментальной группы эффектом воздействия
2. Чтобы оценивать только исходные различия, не сравнивая итоговые результаты
3. Чтобы сопоставлять изменение с условием без изучаемого воздействия
4. Чтобы заменить случайное распределение одинаковыми средними баллами

## Ответ и пояснение

Чтобы сопоставлять изменение с условием без изучаемого воздействия

Сравнение с контрольным условием помогает рассмотреть альтернативные причины изменения — время, тестирование, внешние факторы. Само изменение в экспериментальной группе ещё не доказывает эффект воздействия; сходство исходных средних не заменяет планирование сравнения. Контроль также требует измерений.
